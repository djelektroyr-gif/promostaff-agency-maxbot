# Customer Cabinet Contract (MAX / TG / Web)

Единый контракт для заказчика во всех поверхностях.

## Роль и доступ

- Контур доступен только верифицированному заказчику (`client`).
- Все клиентские действия привязаны к одной компании (`company_id`) в общей БД.

## Проекты

- Показываются только проекты компании клиента.
- Создание проекта проходит через единый gate подписки и лимитов.
- Статусы и причины блокировок совпадают с Telegram и вебом.

## Подписка и лимиты

- Поддерживаемые статусы: `active | trial | grace | expired`.
- Ограничение `projects_limit`: `NULL` = без лимита.
- Создание блокируется, если подписка не активна или лимит исчерпан.

## Команда

- Раздел "Команда" показывает исполнителей, которые уже работали в проектах компании.
- Источник: `workers` + `shift_assignments` + `shifts` + `projects`.

## Отчёты

- Клиентский формат отчётов: Excel/PDF.
- Единые периоды и поля во всех каналах.
- CSV остается для внутренних админских инструментов.

## Инварианты паритета

- Одна логика gate проектов во всех каналах.
- Одинаковый набор статусов подписки/проектов.
- Одинаковая бизнес-логика причин отказов.
