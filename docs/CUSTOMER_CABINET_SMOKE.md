# MAX Customer Cabinet Smoke

Проверка клиентского вертикального среза в MAX после паритета с Telegram/вебом.

## Шаги

1. Открыть `Меню заказчика` → `Мои проекты`.
2. Проверить, что список проектов не заглушка.
3. Нажать `Создать проект`:
   - при доступной квоте проект создаётся;
   - при блоке выводится причина.
4. Нажать `Подписка и лимиты`:
   - видны статус, тариф, лимит, окончание.
5. Нажать `Команда заказчика`:
   - отображаются исполнители компании.
6. Нажать `Отчёты Excel/PDF`:
   - есть переход в защищённый веб-кабинет для выгрузки.

## Pass

- MAX показывает тот же бизнес-контракт, что Telegram и веб.
